# DA-VIBES
DA VIBES AI est une application web intelligente conçue pour transformer un simple sujet textuel en un concept de vidéo sur mesure, guidé par l'émotion recherchée. Elle automatise la création de prompts sophistiqués pour piloter des moteurs de génération de vidéos par intelligence artificielle selon un ton précis (drôle, triste ou amusant).
